# 智能课程知识图谱系统 — 项目总结

---

## 一、系统简介

智能课程知识图谱系统是一个基于图数据库和知识图谱技术的智慧教育平台。它将零散的课程知识点组织成可视化的网状结构，帮助学生建立系统化的知识体系，并为学生提供个性化的学习路径推荐。

系统以「高等数学」课程为示例，预置了 31 个知识点（涵盖基础、极限、导数、积分、微分方程五大模块）和 50 条知识点关系，开箱即可演示完整功能。

**核心价值：** 把分散的知识点变成一张「知识地图」，让学习路径看得见。

## 三、已实现的基础功能（当前系统已完成）

### 功能 1：知识点管理

教师可以创建、编辑、删除知识点，也可以建立知识点之间的关系（前置知识 / 相关概念）。

- **后端 API：** `POST/GET/PUT/DELETE /api/knowledge`
- **关系 API：** `POST/DELETE /api/graph/relations`
- **前端管理 Tab：** 表单创建 + 下拉菜单建立关系

### 功能 2：知识图谱可视化

以 D3.js force-directed graph 展示知识点的网状结构，支持丰富的交互：

- 节点按分类着色（基础/极限/导数/积分/微分方程各一色）
- 节点大小 = 难度系数
- **拖拽**——节点可自由拖动，力导向自动重排
- **滚轮缩放 + 平移**——缩放范围 0.15~5 倍
- **悬浮高亮**——鼠标悬停节点，邻接节点和边高亮，其余半透明
- **点击查看详情**——右侧弹出面板，显示描述、难度星级、关联知识点列表
- **分类筛选**——按五大模块单独展示
- **图例**——左下角颜色说明 + 推荐路径/相关概念标识

### 功能 3：智能学习路径推荐

基于 Neo4j 内置的 `shortestPath` 算法，从学生已掌握知识点出发，到目标知识点计算最短前置链。

- **后端 API：** `POST /api/recommend/path`
- **前端交互：** 右侧「学习路径」Tab → 点击目标节点 → 图谱红色高亮显示路径
- **前置链路查询：** `GET /api/recommend/prerequisites/:id` 查看完整前置链
- **路线图查询：** `GET /api/recommend/roadmap/:id` 从最基础节点到目标

### 功能 4：知识检索

学生搜索知识点名称或描述，图谱自动平移到该节点并高亮定位。

- **后端 API：** `GET /api/knowledge/search?q=xxx`
- **前端交互：** 搜索框输入 → 下拉建议 → 选中后图谱平滑平移到目标节点 + 脉冲环动画

## 四、五大扩展方向

### 扩展一：多课程与多用户体系 ★★★★★

**当前状态：** 只有单套数据（高等数学），没有用户概念。

**改造内容：**

数据模型扩展（Neo4j）：

```cypher
(:Course {id, name, description, created_at})
(:Student {id, name, email, created_at})
(:KnowledgeNode)-[:BELONGS_TO]->(:Course)
(:Student)-[r:HAS_MASTERED {score, updated_at}]->(:KnowledgeNode)
```

- 学生登录后只看到所选课程的图谱
- 推荐路径基于该生个人的「已掌握」记录，而非写死的 `["n1","n2"]`
- 教师端可创建课程、批量导入知识点

**工作量估计：** 后端 2 天 + 前端 2 天

---

### 扩展二：学习进度追踪与薄弱环节分析 ★★★★

**改造内容：**

- 学生在图谱上标记掌握程度（25% / 50% / 75% / 100%）
- 节点颜色随掌握程度渐变：未接触（灰色）→ 学习中（黄色）→ 已掌握（绿色）
- 「薄弱环节分析」算法：如果一个节点的所有前置都已掌握但该节点未掌握，标记为「待突破」节点（红色边框脉冲）
- 个人学习报告：统计已掌握比例、薄弱知识点列表

**工作量估计：** 后端 1.5 天 + 前端 2.5 天

---

### 扩展三：多路径对比与个性化推荐 ★★★★

**改造内容：**

实现多种路径推荐策略并联展示：

| 策略 | 算法 | 适用场景 |
|------|------|---------|
| 最短路径 | `shortestPath`（步数最少） | 快速复习冲刺 |
| 最轻松路径 | 按 `difficulty` 加权（难度和最低） | 基础薄弱学生 |
| 最扎实路径 | 经过中间节点最多（覆盖面最广） | 系统学习 |

前端用三种颜色并行显示多条路径，并排对比步数和总难度。

```cypher
// 最轻松路径
MATCH path = (start)-[:PREREQUISITE*]->(target)
WITH path, reduce(w = 0, n IN nodes(path) | w + n.difficulty) AS cost
RETURN path, cost ORDER BY cost ASC LIMIT 3
```

**工作量估计：** 后端 1 天 + 前端 2 天

---

### 扩展四：知识问答（QA + 资源关联）★★★

**改造内容：**

- 给每个 `KnowledgeNode` 增加 `video_url`、`exercises`、`quiz_id` 等资源字段
- 知识点详情面板中嵌入视频链接和练习题入口
- 自然语言问答引擎（基于 Cypher 模板）：

```
Q: "学xx之前要学什么？"
→ MATCH (pre)-[:PREREQUISITE*]->(target {name: "xx"}) RETURN pre.name

Q: "xx 和 yy 有什么关系？"
→ MATCH (a {name: "xx"})-[r]-(b {name: "yy"}) RETURN type(r)
```

- 可进一步接入 LLM（OpenAI / 本地模型），将自然语言翻译为 Cypher，非 LLM 版本用规则模板能覆盖约 80% 常见问题

**工作量估计：** 后端 2 天 + 前端 1.5 天

---

### 扩展五：课程知识体系扩展与导出 ★★★

**改造内容：**

- 预置更多课程数据：
  - **线性代数**：矩阵 → 行列式 → 特征值 → 特征向量 → 二次型（20+ 节点）
  - **数据结构**：数组 → 链表 → 栈/队列 → 树 → 图 → 排序/查找（25+ 节点）
- 图谱导出为 PNG / SVG，答辩 PPT 直接用
- 节点入度分析：用节点大小表示「被依赖次数」，一眼识别核心基础概念
- dagre 分层布局—按前置关系从上到下排列，比力导向图更适合展示知识层级

**工作量估计：** 数据准备 1.5 天 + 前端 1.5 天
